会议纪要助手 0.3.1 安装与升级说明

该文档合并了安装、依赖和升级说明。默认分发物为 会议纪要助手 0.3.1 安装盘.dmg，其中包含可拖拽安装的 App、Applications 快捷入口和说明文档文件夹。

安装前准备

系统条件

  • macOS 14 或更高版本
  • Apple Silicon Mac
  • 至少 8GB 内存，建议 16GB
  • 至少 8GB 可用磁盘空间，建议 12GB 以上
  • Python 3.12 或更高版本

提前准备

  • 飞书自建应用的 App ID 和 App Secret
  • Hugging Face Token
  • 纪要生成后端配置：默认 Codex CLI，也可使用 OpenAI 兼容 API、Anthropic、LM Studio 或 Ollama
  • ffmpeg
  • LibreOffice

依赖说明

类别用途说明
Python 虚拟环境后台服务运行安装器会自动复用、离线安装或在线创建。
ffmpeg音频转换把录音转换为后续分析所需格式。
LibreOffice导出 PDF把生成的 DOCX 转成 PDF。
LLM 后端会议分类和纪要生成默认 Codex CLI；HTTP 或本地模型后端需填写地址、Key 和模型。
安装器会先检查系统条件。硬性条件不满足时会停止安装；缺少可选工具时会提示，但不一定阻止继续安装。

推荐安装方式

  1. 双击打开 会议纪要助手 0.3.1 安装盘.dmg。
  2. 窗口中左侧是 会议纪要助手.app，右侧是 Applications 文件夹，按中间箭头把 App 拖过去即可。
  3. 在“应用程序”中首次打开 App。App 会自动判断当前用户目录中是否已有安装：
    • 没有：自动部署后台组件和运行环境。
    • 已有：自动按保留数据的升级路径刷新后台文件。
  4. 首次部署完成后，App 会继续进入首次启动向导；已有用户则直接进入主界面。
  5. 首次安装时，按向导填写凭据并完成可用性检查。

依赖安装策略

模式行为适用场景
auto复用现有环境，优先离线，再回退在线安装默认模式
reuse只复用现有虚拟环境已装过且环境可用
offline只从 wheelhouse/ 离线安装封闭网络
online强制在线安装需要重新准备依赖
managed-online自动准备独立 Python 运行时，再创建专用虚拟环境本机缺少 Python 3.12+

首次启动向导

  1. 检查系统环境。
  2. 确认本地录音和会议纪要保存位置；默认分别为 downloads/ 和 sessions/，也可直接改成自定义目录。
  3. 填写飞书 App ID、App Secret、Hugging Face Token 等配置。
  4. 检查飞书接口、Hugging Face 模型访问和纪要生成后端连通性。
  5. 检查通过后即可启动后台服务。
若只检测到低版本 Python，首次启动安装窗口会给出三种处理方式：自动在线安装独立 Python 运行时、 打开本地离线安装包，或直接指定机器上已经存在的 Python 可执行文件。自动在线安装会把运行时放在 当前用户目录中，并在项目内创建独立虚拟环境，不替换系统 Python。若你已有可用虚拟环境，也可以选择其中的 bin/python。
若缺少 ffmpeg、LibreOffice 或默认后端所需的 Codex CLI，首次启动安装窗口也会提示可自动补齐。 该流程会通过 Homebrew 安装缺失工具；若机器尚无 Homebrew，系统可能还会要求你完成一次额外确认。 Codex CLI 安装后仍需由本人完成登录；如果使用其他 LLM 后端，请在向导或 .env 中填写对应 API 配置。

纪要生成后端

LLM_PROVIDER=codex
LLM_API_BASE=
LLM_API_KEY=
LLM_MODEL=
LLM_TIMEOUT_SECONDS=600

codex 为默认后端；openai 可接入 OpenAI、DeepSeek、Kimi、通义千问、智谱等兼容服务； anthropic 使用 Anthropic API；lm-studio 和 ollama 用于本机模型服务。

推荐转写性能配置

ASR_MODEL=medium
ASR_LANGUAGE=zh
ASR_CPU_THREADS=16
ASR_BATCH_SIZE=8
ASR_BEAM_SIZE=5

默认配置使用 faster-whisper CPU int8、16 线程和批量转写。增加线程数或批量大小会提高资源占用； 减小模型或 beam size 可以进一步提速，但可能降低中文准确率。Apple Silicon 上说话人分离会自动优先使用 Apple GPU。

升级说明

已安装用户仍然使用同一份 安装盘.dmg 即可。把新版 App 拖入 Applications 覆盖旧版后，再打开 App，程序会自动识别为升级， 并保留 .env、已有保存位置、历史会议、下载文件、独立日志目录、library/ 和本地模板。 新版默认支持目录为 $HOME/Library/Application Support/meeting-bot，日志目录为 $HOME/Library/Logs/meeting-bot。如果旧版仍在 $HOME/Library/Application Support/meetin-bot、 $HOME/Library/Application Support/feishu-meeting-bot、$HOME/meetin-bot、 $HOME/meeting-bot 或 $HOME/feishu-meeting-bot，新版会自动迁移，并改写仍指向旧根目录的默认保存位置。 升级完成后会继续打开新版 App，并移除旧名称对应的旧应用包。

若旧版本曾把后台服务禁用，当前版本在“启动”或“重启”时会先尝试恢复 LaunchAgent，再继续加载服务。

命令行备用方式

bash scripts/install.sh --dependency-mode auto
bash scripts/doctor.sh
bash scripts/upgrade.sh

常见检查

  • 首次安装后，如需排查环境，可运行 scripts/doctor.sh。
  • 后台服务配置位于 $HOME/Library/LaunchAgents/com.pgui.feishu-meeting-bot.plist。
  • 若 codex 或 ffmpeg 不在默认 PATH 中，可在配置中填写绝对路径；使用其他 LLM 后端时请检查 LLM_PROVIDER、地址、Key 和模型。
  • 若首次启动安装失败，App 会显示错误，并把详细日志写入 ~/Library/Logs/meeting-bot/首次启动安装.log。
  • 芯片检查会同时识别原生 arm64 和具备 arm64 能力的 Apple Silicon 机器，避免兼容环境造成误判。
  • 构建载荷会排除 .git 和本地运行数据；完整安装会清理旧 App 资源，避免残留文件破坏签名。
