# 会议纪要助手 分享清单

如果需要把这个 App 分享给其他人，建议至少准备以下材料。

## 默认只需提供

- 安装盘：`dist/会议纪要助手 0.5.0 安装盘.dmg`
- 发布元数据：`dist/release-manifest-0.5.0.json`

该 `dmg` 内只包含：

- `会议纪要助手.app`
- `Applications` 快捷入口
- 安装与升级说明：`安装与升级说明.html`
- 使用说明：`使用说明.html`
- 更新记录：`更新记录.md`
- 开发路线图：`开发路线图.md`

## 对方需要自行准备

- 自己的 `FEISHU_APP_ID`
- 自己的 `FEISHU_APP_SECRET`
- 自己的 `HF_TOKEN`
- 纪要生成后端：默认可使用已登录的 Codex CLI，也可改用 OpenAI 兼容 API、Anthropic、LM Studio 或 Ollama
- 本机可用的 `ffmpeg`
- 本机可用的 LibreOffice

## 不应分享

- 你的 `.env`
- 你的 `.venv`
- `sessions/`
- `downloads/`
- `logs/`
- `runtime/`
- `library/`
- 任何真实会议录音、转录稿、纪要文件
- 任何带有个人密钥或企业数据的截图

## 建议额外提供

- 3 到 4 张软件截图：
  - 状态栏弹窗
  - 主界面概览
  - 会议库
  - 正式纪要示例
- 一份简短的首次使用说明：
  1. 安装系统依赖
  2. 填写 `.env`
  3. 运行 `scripts/doctor.sh`
  4. 打开 App
- 若对方会直接从本地材料建会，可补充说明“会议库 -> 新增会议”支持录音、现成转录稿、手动会议类型和额外导出格式。
- 内部试用可以只提供 `dist/会议纪要助手 0.5.0 安装盘.dmg`；正式分发应同时提供 `release-manifest-0.5.0.json`，并在受保护的发布环境中附加 ECDSA P-256/SHA-256 签名。
- 首次打开 App 后会自动部署后台组件；首次安装会进入配置向导，升级会直接进入新版界面。
- 若分享给非开发用户：
  - 直接提供安装盘
  - 如目标环境不能联网，可额外提供带 `wheelhouse/` 的离线安装包
  - 使用 Developer ID 签名并完成 Apple 公证、stapling 的 `.app` 与安装盘
  - 一份常见问题说明
  - 可选的演示录音或脱敏示例数据

## 开发或排障资料

- 配置模板：`.env.example`
- 其他脚本和构建产物只保留在工程内，不作为对外交付文件。
