# 更新记录

## 0.3.0

- 纪要生成不再绑定 Codex CLI：新增 `LLM_PROVIDER` 配置，可选 codex（默认）、任意 OpenAI 兼容 API（OpenAI、DeepSeek、Kimi、通义千问、智谱等）、Anthropic API，以及本地部署的 LM Studio 和 Ollama；本地服务未指定模型时自动选用服务端已加载的模型。设置页和首次启动配置向导提供后端选择、API 地址/Key/模型填写及连通性检查。
- 重绘状态栏"处理中"动画：声波样式改为 5 根相位错开的均衡器跳动条，脉冲样式改为三点依次弹跳；自绘渲染，Retina 下清晰，跟随用户配色。
- 修复"中止"新增会议的进程清理：处理脚本自成进程组，中止时整组终止（含 ffmpeg、LLM、LibreOffice 子进程），5 秒未退出强制结束；中止后自动删除半成品会话目录，不再残留占用磁盘。
- 修复任务崩溃后状态栏永远显示"处理中"的问题：后台服务启动时通过本地会议互斥锁判断任务是否真的在运行，陈旧状态自动重置为空闲；状态文件新增 source 字段，中止本地会议不再误覆盖飞书机器人正在处理的任务状态。
- 统一匿名说话人编号：所有生成路径（首次生成、重新生成、导出、界面显示）一律按声纹 ID 编号（SPEAKER_00 → 说话人1），消除重新生成后"说话人 N"变号的问题；相关逻辑收敛到共享模块 `speaker_naming.py`。
- 界面向 macOS 原生风格重构（进行中）：新增统一设计 token（间距、圆角、品牌青绿色、语义状态色，见 `DesignSystem.swift`）；会议列表项重设计为「类型图标锚点 + 标题 + 日期/发言人数/类型 + 状态圆点」；会议库主界面由手搓 HSplitView 三栏改为原生 `NavigationSplitView` 三栏；顶部手搓标签栏与底部状态栏改为原生统一工具栏（新增会议、标签/时间筛选、刷新、显示模式、设置）与原生 `.searchable` 搜索，侧边栏采用原生 source-list 半透明材质；本地会议处理进度与「中止」移至列表底部浮条；主窗口强调色由系统蓝统一为品牌青绿。
- 「概览」页改为顶部「概览 / 会议库」原生分段切换，默认显示、整窗切换（可在设置→外观关闭概览）；保留概览页现有全宽布局。
- 会议库工具栏图标固定在标题栏最右、收为一组，不再随筛选文字长度变化左右浮动；标签与时间筛选改为纯图标按钮。
- 设置、新增会议、原始转录三个独立窗口的强调色同步为品牌青绿。
- 修复原始转录窗口音频进度条拖拽 / 点击卡顿：转录段抽为独立行视图，仅高亮状态变化的段重绘，避免整列 `TextEditor` 重绘风暴；播放刷新频率降至 0.5 秒。

## 当前开发版（0.2.14 后）

- 所有会议处理阶段均基于原有状态栏图标播放动画，不再在生成纪要等阶段显示带圈声波；声波图标在 0.5 秒内由左向右单向律动，脉冲图标滚动跳动，动作完成后暂停 1 秒再重复。
- 原始转录录音进度条改为拖动时只预览时间、松手后执行一次音频跳转，避免连续精确跳转造成卡顿。
- 会议库保存说话人标注后，会同步更新 `speaker_map.json`，并自动重新生成实名转录稿、会议纪要及已有导出格式；清空姓名后恢复匿名版。
- 统一说话人显示规则：内部 `SPEAKER_00` 显示为“说话人1”，`UNKNOWN` 及旧称“说话人未知”统一显示为“未知说话人”；内部稳定 ID 仍保留在原始数据中。
- 说话人分离新增分阶段实时进度，Apple Silicon 上优先使用 MPS GPU，不兼容的步骤自动回退 CPU。
- 语音转写新增实时百分比和已处理时长；默认启用 faster-whisper CPU int8、16 线程、批量大小 8、beam size 5，实测同一 2 分钟片段较原配置快约 2.17 倍。
- 新增会议的录音和转录稿支持拖拽添加；关闭新增会议窗口后，主窗口底部仍显示处理进度并提供“中止”按钮。
- 新增会议增加跨进程互斥保护，避免应用重开或重复点击后同时处理同一任务、争抢 CPU。
- 会议详情右侧的标题、“撤销”和“保存”按钮改为固定操作栏，不再随正文滚动。
- App 构建载荷排除 `.git`，完整安装时删除旧资源残留，避免运行后破坏应用包签名。
- 转写文本统一转换为简体中文。
