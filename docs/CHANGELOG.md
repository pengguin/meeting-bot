# 更新记录

## 0.7.0

- 新增统一持久化任务账本，本地新增/重试与飞书消息任务共用任务 ID、来源、优先级、阶段、检查点、重试、错误和产物引用模型。
- 建立有限状态机，约束排队、运行、暂停、取消、失败、等待用户、重试和完成之间的合法转换；非法转换失败关闭且不改写原任务。
- 飞书消息先登记任务再进入有界执行器；消息 ID 与会话主体只保存 SHA-256 摘要，重复事件跨进程收敛为同一个任务。
- 本地草稿状态保存任务 ID，暂停或纪要失败后继续处理会复用原任务、保留检查点并累计重试次数。
- 后台启动时原子审计未完成任务：失去执行进程的本地任务转为暂停，无法安全重放的飞书任务转为等待用户处理。
- 运行状态镜像增加任务 ID；阶段更新同步到账本但不记录会议正文或飞书聊天内容。
- 新增任务账本检查、审计、重试和取消命令行入口；保留旧消息去重器作为兼容层，并修复其原子写入后的顺序保持。
- 全量自动化测试增加到 110 项；版本号推进到 `0.7.0`，构建号推进到 `36`。

## 0.6.0

- 新增统一持久化层：跨进程文件锁、受限读取、符号链接拒绝、原子替换、父目录同步、私有权限和写前备份由同一模块实现。
- 会议来源元数据、本地草稿状态、请求、检查点、运行状态和完成事件增加数据版本与文档类型；旧版无版本文件兼容读取，新版文件拒绝未知高版本。
- 损坏的会议元数据或草稿文件不再被空对象或新状态覆盖；重复材料检查会跳过损坏会话并保留原文件。
- Swift 会议库元数据增加版本检查和保存前有效备份；解码失败继续保持写保护。
- 新增只读扫描、显式隔离损坏文件和从 `.bak` 恢复的本地数据恢复工具，并限制其只能处理用户指定根目录内的文件。
- 转录、说话人映射、纪要 JSON 和关键文本产物统一使用原子写入。
- 全量自动化测试增加到 104 项；版本号推进到 `0.6.0`，构建号推进到 `35`。

## 0.5.0

- 新增贴近真实消息流的集成测试：覆盖飞书凭据复用、引用消息解析、分块下载和大小限制，覆盖 ffmpeg 参数、ASR 模型复用、转写进度、说话人分离排序与状态回调，并覆盖运行状态、完成事件和陈旧任务恢复。
- 会议库扫描迁移到独立 Swift actor，文件读取不再阻塞主线程；按会话文件数量、总大小、最新修改时间和任务锁状态维护内存增量索引，未变化会议复用缓存记录，连续刷新请求自动合并。
- 会议库扫描时底部状态栏显示“正在更新会议库”及进度图标，刷新按钮暂时禁用，避免用户重复触发扫描；扫描结果回到主线程后统一更新列表与选择状态。
- App 打包载荷新增逐文件 SHA-256 清单、版本、构建号、最低系统版本和载荷编号；首次安装或升级会在修改旧版本前校验清单，缺失、损坏或被篡改时直接停止并显示可读错误。
- 安装盘构建后额外生成 `release-manifest-0.5.0.json`，记录安装盘文件名、大小和 SHA-256；构建脚本支持通过 `MEETINGBOT_RELEASE_SIGNING_KEY` 与 `MEETINGBOT_RELEASE_PUBLIC_KEY` 附加 ECDSA P-256/SHA-256 签名。当前本地交付仍为 ad-hoc 签名，Developer ID 签名与 Apple 公证仍需真实发布证书。
- 新增独立开发路线图 `docs/DEVELOPMENT_ROADMAP.md`，按 0.6、0.7、0.8、0.9 和 1.0 列出开发主题、验收条件与发布门槛。
- 自动化测试增加到 57 项；版本号推进到 `0.5.0`，构建号推进到 `32`。

## 0.4.0

- 合并原定 0.3.3 与 0.4 的开发内容：本地新增录音或转录稿后立即建立临时会议条目，音频预处理、说话人分离、语音转写、对齐、分类、纪要和导出阶段均写入检查点；暂停、崩溃或 App 重开后复用已完成产物继续处理，不再重复执行已完成的说话人分离或转写。
- “中止”调整为“暂停”：暂停会保留原录音、转录稿和阶段产物；无转录稿时可在原条目继续处理，已有转录稿但纪要失败时可直接重试生成纪要。重试任务会持久化“处理中 / 失败 / 完成”状态，App 重开后仍可正确显示。
- 修复重生成脚本参数及草稿判定问题：纪要 JSON 已生成但导出失败时不再误判为完成；重试会沿用原导出格式，并在成功后把临时条目转为正式会议。
- 纪要生成增加严格 JSON 结构校验、原子写入、有限退避重试和可读错误分类；登录失效、额度不足、限流、网络故障、超时或返回格式异常时均保留转录结果，并提示在会议库稍后重试。
- 飞书后台增加有上限的任务队列、跨重启消息去重、飞书访问凭据缓存和下载大小限制；ASR 与说话人分离模型改为首次任务按需加载，降低空闲内存与启动等待。
- 飞书 App Secret、Hugging Face Token 和 LLM API Key 改存 macOS 系统钥匙串；旧 `.env` 保持兼容，用户下次保存设置时自动迁移。远程 LLM 地址强制使用 HTTPS，本机服务仍允许 HTTP。
- 安装与升级改为事务式处理：覆盖前备份运行组件，Python 环境与 App 分别保留可恢复副本；任一阶段失败会恢复旧版并保留会议、录音和配置。安装窗口显示当前阶段、恢复结果并轮转过大日志。
- 可选工具安装不再自动执行 Homebrew 网络安装脚本；未安装 Homebrew 时提供官网入口，用户确认安装后再继续补齐 ffmpeg、LibreOffice 或 Codex CLI。
- 设置中的录音目录和会议目录迁移改为统一预检、统一执行，发生错误时反向恢复；会议处理进度刷新增加节流，降低长会话持续更新时的会议库扫描开销。
- 版本号推进到 `0.4.0`，构建号推进到 `31`。

## 0.3.2

- 本地新增会议失败不再前功尽弃：转录稿生成后、纪要生成阶段若失败（非用户主动中止），会议会作为「草稿」保留在会议库，详情页与右键菜单提供「重试生成纪要」，复用已生成的转录稿重跑纪要，无需从头转写。用户主动「中止」仍按原行为删除半成品会话目录。
- 失败提示简化：草稿详情只显示一句「新增会议失败」，完整报错收进旁边的圆圈感叹号，点开可查看 / 复制；「内容」区在草稿状态下不再重复显示报错。
- 转录稿都还没生成就中断 / 失败的草稿（例如转写阶段崩溃），现提供「重新处理」：复用草稿目录里保存的原始录音，在原会话目录里原地重跑转写、说话人分离与纪要生成；这条草稿直接从「中断」变回「处理中」，不产生第二条草稿、不复制或移动录音。
- 草稿会议在会议库中可识别：列表状态圆点区分「处理中」（处理色）与「处理未完成 / 可重试」（错误色），详情页显示当前处理阶段；新增会议过程中界面会实时跟随显示该草稿的处理进展。
- 处理进程崩溃 / 被强杀导致状态停在「处理中」的陈旧草稿，现可被识别：通过本地会议互斥锁判断处理进程是否真的在运行，锁已释放则把陈旧「处理中」草稿标记为可重试 / 可重新处理，不再卡死无入口。
- 后端将本次新增会议的请求参数（标题、模板、导出格式）与处理状态快照分别落盘到会话目录（`local_meeting_request.json` / `local_meeting_state.json`），作为草稿识别与重试复用的依据；相关读写逻辑抽出为独立轻量模块 `local_meeting_drafts.py` 并补充单元测试。
- 版本号推进到 `0.3.2`，构建号推进到 `30`。

## 0.3.0

- 纪要生成不再绑定 Codex CLI：新增 `LLM_PROVIDER` 配置，可选 codex（默认）、任意 OpenAI 兼容 API（OpenAI、DeepSeek、Kimi、通义千问、智谱等）、Anthropic API，以及本地部署的 LM Studio 和 Ollama；本地服务未指定模型时自动选用服务端已加载的模型。设置页和首次启动配置向导提供后端选择、API 地址/Key/模型填写及连通性检查。
- 重绘状态栏"处理中"动画：所有处理阶段都基于用户当前选择的原状态栏图标播放动画，不再在生成纪要等阶段切换到带圈声波；声波样式 0.5 秒内由左向右单向律动，脉冲样式滚动跳动，动作完成后暂停 1 秒再重复。
- 修复"中止"新增会议的进程清理：处理脚本自成进程组，中止时整组终止（含 ffmpeg、LLM、LibreOffice 子进程），5 秒未退出强制结束；中止后自动删除半成品会话目录，不再残留占用磁盘。
- 修复任务崩溃后状态栏永远显示"处理中"的问题：后台服务启动时通过本地会议互斥锁判断任务是否真的在运行，陈旧状态自动重置为空闲；状态文件新增 source 字段，中止本地会议不再误覆盖飞书机器人正在处理的任务状态。
- 统一匿名说话人编号：所有生成路径（首次生成、重新生成、导出、界面显示）一律按声纹 ID 编号（SPEAKER_00 → 说话人1），消除重新生成后"说话人 N"变号的问题；相关逻辑收敛到共享模块 `speaker_naming.py`。
- 界面向 macOS 原生风格重构（进行中）：新增统一设计 token（间距、圆角、品牌色、语义状态色，见 `DesignSystem.swift`）；会议列表项重设计为「类型图标锚点 + 标题 + 日期/发言人数/类型 + 状态圆点」；会议库主界面由手搓 HSplitView 三栏改为原生 `NavigationSplitView` 三栏；顶部手搓标签栏与底部状态栏改为原生统一工具栏（新增会议、标签/时间筛选、刷新、显示模式、设置）与原生 `.searchable` 搜索，侧边栏采用原生 source-list 半透明材质；本地会议处理进度与「中止」移至列表底部浮条；主窗口强调色支持蓝、绿、灰三套配色方案。
- 「概览」页改为顶部「概览 / 会议库」原生分段切换，默认显示、整窗切换（可在设置→外观关闭概览）；保留概览页现有全宽布局。
- 会议库工具栏图标固定在标题栏最右、收为一组，不再随筛选文字长度变化左右浮动；边栏按钮移动到会议库专属工具组之前，并且边栏、新增会议、标签、时间、刷新只在会议库页显示。
- 设置、新增会议、原始转录三个独立窗口的强调色同步为当前配色；设置页“外观”新增蓝、绿、灰配色方案，状态栏图标选中态使用浅色主题高亮。
- 修复原始转录窗口音频进度条拖拽 / 点击卡顿：转录段抽为独立行视图，仅高亮状态变化的段重绘，避免整列 `TextEditor` 重绘风暴；高亮段改为二分查找 + 状态缓存，仅跨段时更新，播放刷新频率降至 0.5 秒，适配长音频。
- 主窗口顶部改为固定布局：「概览 / 会议库」切换贴左、操作图标恒定贴右（不再随窗口宽度或左侧栏有无而移动）；概览页整片显示概览内容（隐藏文件夹与会议列表栏）；底部恢复会议汇总与本地处理进度状态栏；侧边栏开关与搜索框回归侧边栏；设置中移除「显示概览标签页」开关，概览作为固定标签常驻。
