# 会议纪要助手 0.2.14 使用说明

## 推荐阅读方式

- 面向普通使用者，优先打开 `docs/SOFTWARE_GUIDE.html`。该版本带有界面说明、按钮说明和截图区域，更适合作为交付版说明页。
- 面向维护者，可继续阅读当前 Markdown 版本，便于检索和后续编辑。

## 软件定位

会议纪要助手是一个本地运行的飞书会议助手。它接收飞书聊天中的会议录音或转录文字材料，在本机完成音频转写、说话人分离、会议类型识别和纪要生成，并把正式纪要回传到飞书。

## 核心能力

- 接收飞书音频或文件消息，支持常见音频格式：`m4a`、`mp3`、`wav`、`aac`、`flac`、`ogg`、`opus`、`mp4`、`mov`、`webm`。
- 接收已转录文字材料：`txt`、`md`、`markdown`、`csv`、`srt`、`vtt`。
- 对音频执行 16 kHz 单声道转换、说话人分离、语音转写、说话人对齐。
- Apple Silicon 上说话人分离优先使用 Apple GPU；语音转写默认启用 16 线程和批量处理。
- 说话人分离和语音转写均显示实时处理进度。
- 自动判断会议类型，并生成结构化会议报告。
- 默认输出 HTML 和 DOCX，可按需追加 PDF、MD。
- 默认不在飞书对话中展开完整转录稿，只发送摘要和正式纪要文件。
- 支持重复材料复用：同一音频或文字材料已处理过时，默认跳过重复转写，只重新汇编纪要。
- 支持引用历史音频并回复“重新生成会议纪要”。
- 支持引用音频并回复“重新转录”，强制重新跑 ASR。
- 支持会后补充说话人身份，例如 `说话人1=张老师`，并重新生成实名版纪要。
- 保存说话人标注后，会同步更新原始转录稿、会议纪要及已有导出文件。
- 转写结果统一整理为简体中文。

## 典型使用方式

### 发送录音生成纪要

在飞书中直接给机器人发送会议录音文件。机器人会提示已收到文件，然后完成转写和报告生成。

### 上传转录文字生成纪要

直接上传 `txt/md/srt/vtt/csv` 文件，或粘贴较长转录文本。机器人会跳过音频转写，直接生成会议纪要和报告文件。

### 复用历史录音

引用已经上传过的音频消息，回复：

```text
重新生成会议纪要
```

如果本地已有该音频的转录结果，机器人会跳过重复转写。

### 强制重新转录

引用音频消息，回复：

```text
重新转录
```

机器人会重新下载音频并完整执行转写流程。

### 更新说话人身份

匿名版生成后，可以继续回复：

```text
说话人1=我
说话人2=张老师
```

机器人会更新说话人映射，并重新生成实名版摘要和正式纪要文件。

### 查看说话人

回复：

```text
查看说话人
```

机器人会返回最近一次任务的声纹标签和当前显示名称。

## 本地菜单栏 App

菜单栏 App 用于查看和控制本机后台服务：

- 查看服务状态和当前任务阶段。
- 查看本地 Python、`ffmpeg`、LibreOffice、Codex CLI 和核心配置是否就绪。
- 启动、停止、重启后台机器人。
- 在主界面中打开项目目录、会话目录、日志目录和错误日志。
- 打开最近一次会议的 PDF、DOCX、HTML、MD 文件。
- 左键点击状态栏图标打开轻量弹窗，右键可打开主界面或退出。
- 轻量弹窗会根据异常内容自动增高；右上角可直接打开主界面。
- 轻量弹窗仅保留高频控制按钮，减少重复信息和低频入口。
- 通过独立窗口中的“会议库”浏览历史纪要，按标题、正文、标签、备注或人工标注的说话人搜索。
- 可在会议库中直接新增本地会议：导入录音、现成转录稿，或同时保留两者；可手动指定会议类型和额外导出文件。
- 新增会议支持把录音或转录稿直接拖入对应材料栏。
- 新增会议开始处理后可以关闭新增窗口；主界面底部会继续显示实时进度，并提供“中止”按钮。
- 为会议添加标签，并为各 session 中的说话人做人工命名；相同标签或姓名会用于跨 session 关联。
- 为会议补充个人备注，记录会后提醒、检索线索或补充信息。
- 主界面的“近期会议”可直接跳转到会议库详情；主题关联会结合标签和近似标题匹配，不再只依赖完全相同的主题名。
- 会议库支持按单日或时间段筛选；日期弹层会突出显示已有会议的日期。
- 每场会议可单独补充真实会议时间，系统会同时保留纪要生成时间和真实会议时间。
- 会议详情页中的纪要类型会以中文显示，并可直接下拉切换；切换后会先询问是否重新生成纪要文件。
- 会议详情页支持统一“保存”和“撤销”，便于集中确认标签、备注、会议时间和说话人标注修改。
- 会议详情页的标题、“撤销”和“保存”固定在右侧顶部，不随正文滚动。
- 同一时刻只允许一个本地新增会议任务运行，避免重复任务争抢资源。
- 标签区支持一次新增多个标签，例如输入 `会议，科研` 会生成两个标签并直接同步到当前会议。
- 会议详情页和概览页最近一次会议中的 HTML、DOCX、MD、PDF 文件按钮在对应文件缺失时，可通过右键菜单直接补生成该文件；生成完成后会切换为可打开状态。
- 主窗口底部状态栏会在概览页显示版本号，在会议库显示刷新按钮和会议汇总统计。
- 本地新增会议正在处理时，主窗口底部状态栏会显示当前阶段、百分比或已处理时长，并提供“中止”按钮。
- 主界面支持跟随系统外观、白天、夜览三种配色模式。
- 显示模式会同步作用于设置页、首次向导、安装窗口、转录窗口和状态栏弹窗。
- 设置页“外观”可选择状态栏图标方案（声波、脉冲）和图标颜色（白色、黑色）。
- 主界面顶部右侧可直接打开“设置”；“会议库”标签页选中态已增强。
- 对外只分发图形化安装盘：双击 `dmg` 后将 App 拖入 `Applications`，首次打开时会自动完成本地部署或升级。
- 首次启动时会进入配置向导，依次完成系统检查、保存位置确认、凭据填写、飞书/Hugging Face/Codex 可用性检查。

## 界面说明

### 状态栏弹窗

- `打开主界面`：打开独立窗口。
- `启动` / `停止` / `重启`：控制后台机器人服务。
- `运行状态`：集中显示服务、任务、环境三类信息。
- `最近一次会议`：快速查看最近报告，并打开对应正式文件。

### 主界面概览

- `功能`：集中放置常用文件夹入口和“完成后通知”设置。
- `状态`：展示服务状态、任务状态和最近更新时间。
- `运行环境`：展示 Python、`ffmpeg`、LibreOffice、Codex CLI 等检查结果；当 `ffmpeg` 异常时，会出现一个用于尝试修复的图标按钮。
- `最近一次会议`：展示最近会议摘要，并可打开正式文件。
- `近期会议`：查看近期会议列表。
- `夜览` / `白天`：切换主界面配色。

### 会议库

- `搜索框`：可按标题、正文、标签、备注或说话人检索。
- `标签`：按人工标签过滤。
- `时间`：按全部、单日或时间段过滤；有会议的日期会在日期控件中突出显示。
- `备注`：给单场会议补充便于回忆的个人信息。
- `真实会议时间`：允许人工填写真实会议发生时间，和系统生成纪要时间分开保存。
- `说话人`：支持人工命名，并用于跨 session 关联；保存后自动同步更新转录稿和会议纪要。
- `新增会议`：选择或拖入本地录音、转录稿，直接进入既有转写和纪要工作流。
- `中止`：新增会议处理期间可在新增窗口或主界面底部停止实际处理进程。
- `纪要类型`：中文显示，可在会议详情页直接切换模板，并按提示重新生成文件。

### 处理工作流与进度

音频会议按以下顺序处理：

1. 转换为 16 kHz 单声道 WAV。
2. 说话人分离：显示检测语音活动、提取说话人特征等分阶段进度；Apple Silicon 默认优先使用 MPS GPU。
3. 语音转写：显示百分比及“已处理时长 / 总时长”。
4. 对齐文字与说话人时间轴。
5. 识别会议类型、生成会议纪要并导出文件。

说话人分离只判断“谁在什么时间说话”，语音转写负责识别“具体说了什么”，因此两者会依次执行，并非重复处理。

### 说话人显示规则

- 内部稳定标签 `SPEAKER_00`、`SPEAKER_01` 分别显示为“说话人1”“说话人2”。
- `UNKNOWN` 统一显示为“未知说话人”。
- 标注真实姓名并保存后，会议库、转录稿和会议纪要均显示真实姓名。
- 原始分段 JSON 保留内部稳定标签，用于后续重新映射和编辑。

### 转写性能配置

默认配置在保持 `medium` 模型和 `beam size 5` 的前提下，启用 CPU int8、16 线程及批量大小 8。可在 `.env` 中调整：

```text
ASR_MODEL=medium
ASR_LANGUAGE=zh
ASR_CPU_THREADS=16
ASR_BATCH_SIZE=8
ASR_BEAM_SIZE=5
```

- 增大 `ASR_CPU_THREADS` 或 `ASR_BATCH_SIZE` 通常能提高速度，但会增加 CPU 和内存占用。
- 减小模型或 `ASR_BEAM_SIZE` 可以进一步提速，但可能降低中文准确率。
- faster-whisper 在当前 macOS 配置下使用 CPU；Apple GPU 用于说话人分离。

### 设置

- `状态与服务`：集中管理服务、环境检查和运行状态。
- `外观`：控制主界面标签页显示、顺序和外观模式。
- `高级设置`：维护保存位置、机器人配置、语音转写引擎和底层工具路径。
- `纪要设置`：维护标签和会议类型模板。

## 本地目录说明

- 默认后台支持目录为 `~/Library/Application Support/meeting-bot/`。
- 默认本地录音目录为 `~/Library/Application Support/meeting-bot/downloads/`，用于保存飞书下载的原始文件缓存；可在“设置 -> 高级设置 -> 保存位置”中修改。
- 默认会议纪要目录为 `~/Library/Application Support/meeting-bot/sessions/`，用于保存每次会议的音频副本、转录稿、报告 JSON 和正式文件；可在“设置 -> 高级设置 -> 保存位置”中修改。
- `runtime/status.json`：后台服务当前状态，菜单栏 App 会读取它。
- `runtime/events/`：会议完成事件，菜单栏 App 用于展示最近会议和发送通知。
- `~/Library/Logs/meeting-bot/`：后台标准输出和错误日志。
- `schemas/`：Codex 输出 JSON Schema。

## 注意事项

- 所有录音和纪要默认保存在本机。
- 飞书 App Secret、Hugging Face Token 等密钥只写入本机 `.env`，不要放入发行包或公开仓库。
- PDF 生成依赖 LibreOffice。
- 说话人分离依赖 Hugging Face Token，并需要接受 pyannote 模型条款。
- 报告生成依赖 Codex CLI，安装后需要先完成登录。
- 若需要将软件分享给其他人，请同时提供 `docs/SHARE_CHECKLIST.md` 中列出的材料，并避免带出任何真实会议数据和本机密钥。
